# 2. Требования по Вигерсу

## Бизнес-правила (BR)

| Правило | Описание |
|---|---|
| Запрет дистанционной продажи | Дистанционная продажа табачной и алкогольной продукции запрещена. |
| Электронный чек | Клиенту должен выдаваться электронный чек в соответствии с Федеральным законом № 54-ФЗ. |
| Минимальная стоимость заказа | Минимальная стоимость заказа — 700 рублей (семьсот рублей). |

## Пользовательские требования (UR)

| Пользователь | Требование |
|---|---|
| Покупатель | Покупатель должен иметь возможность просматривать магазины и товары в каталоге. |
| Покупатель | Покупатель должен иметь возможность формировать корзину товаров выбранного магазина. |
| Покупатель | Покупатель должен иметь возможность оплачивать заказ банковской картой. |
| Покупатель | Покупатель должен иметь возможность согласовать замену товара, отсутствующего при сборке заказа. |
| Покупатель | Покупатель должен иметь возможность получить возврат денег за отсутствующий товар. |
| Покупатель | Покупатель должен иметь возможность просматривать статусы своего заказа. |
| Покупатель | Покупатель должен получать электронный чек. |
| Сотрудник магазина | Сотрудник магазина должен иметь возможность выполнять сборку заказа и согласовывать замену отсутствующего товара с покупателем. |

## Функциональные требования (FR)

| Функция | Требование |
|---|---|
| Каталог | Система должна предоставлять каталог магазинов и товаров. |
| Корзина | Система должна поддерживать формирование корзины покупателя. |
| Проверка минимальной суммы | Система должна проверять сумму заказа и не допускать оформление заказа на сумму менее 700 рублей. |
| Проверка запрещённых товаров | Система должна исключать возможность оформления заказа на табачную и алкогольную продукцию. |
| Оплата | Система должна поддерживать оплату заказа банковской картой. |
| Сборка заказа | Система должна поддерживать процесс сборки заказа сотрудником магазина. |
| Отсутствие товара при сборке | Если при сборке заказа товар отсутствует, система должна поддерживать согласование замены с покупателем либо возврат денег за отсутствующий товар. |
| Назначение курьера | Система должна поддерживать назначение курьера на заказ. |
| Статусы заказа | Система должна отображать покупателю статусы заказа. |
| Электронный чек | Система должна обеспечивать выдачу клиенту электронного чека в соответствии с Федеральным законом № 54-ФЗ. |

## Нефункциональные требования (NFR)

| Показатель | Требование |
|---|---|
| Срок доставки | Через четыре месяца после запуска не менее 90% заказов должны доставляться за время не более 60 минут. |
| Актуальность остатков | TBD — допустимый срок обновления сведений об остатках товаров требует уточнения: числовое значение во вводной не указано. |

## Ограничения (CON)

| Ограничение | Описание |
|---|---|
| Ассортимент | Дистанционная продажа табачной и алкогольной продукции запрещена. |
| Электронный чек | Выдача электронного чека клиенту должна соответствовать Федеральному закону № 54-ФЗ. |
| Минимальная сумма заказа | Минимальная стоимость заказа — 700 рублей. |
| Территория доставки | Доставка за пределы района не входит в MVP. |
| Несколько магазинов | Заказ из нескольких магазинов в одной доставке не входит в MVP. |
| Подписки и регулярные заказы | Подписки и регулярные заказы не входят в MVP. |
| Программа лояльности | Программа лояльности не входит в MVP. |
| Учёт остатков в магазинах | У половины магазинов нет учётной системы, остатки ведутся в тетрадке. Это условие необходимо учитывать при организации работы с данными магазинов. |
